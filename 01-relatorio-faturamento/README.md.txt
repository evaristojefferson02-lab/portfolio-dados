# 📊 Relatório de Faturamento

O que este código faz:
- Lê dados de produtos e vendas
- Calcula total e média
- Mostra quais produtos venderam mais
- Salva tudo pronto em arquivo CSV

Arquivos aqui:
- relatorio_faturamento.ipynb → código que executa
- dados_vendas.csv → dados de exemplo
- resultado_final.csv → relatório pronto
